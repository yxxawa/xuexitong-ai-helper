# 程序题与粘贴支持

1.0.7 支持超星的 CodeMirror 程序题（类型 17），用于作业、考试和章节测试的程序编辑器。

当前页面将粘贴标记为 paste，随后在 CodeMirror 的 beforeChange 回调里取消变更并提示“只能录入不能粘贴”。旧版复制粘贴处理只移除了 UEditor 的回调，因此不能解决程序题。

更新完整版脚本后，直接在程序编辑区按 Ctrl+V，或通过右键菜单粘贴。实现从当次原生粘贴事件获取纯文本，使用 CodeMirror 的公开编辑接口替换选区；无需读取系统剪贴板的额外权限。保留缩进、换行、注释、选区替换、撤销及原有其他编辑校验，翻页或延迟创建的编辑器也会启用。

自动答题将当前语言（例如 Python 3.6.9）加入题目，以一个完整的代码字符串读取答案，通过编辑器 API 回填，并同步 backing textarea 与程序题的 JSON 保存字段。编辑器未加载、只读、写入失败或任务取消时不标记完成。已填代码支持跳过和答案检验；结果显示保留源码，不把代码中的 # 分割成多空。

安装文件位于 dist/xuexitong-ai-helper.common.user.js。只需要粘贴功能时，可选择 dist/chaoxing-programming-paste.user.js；该文件也可直接复制到当前题目页控制台运行。独立助手和完整版共享同一份实现，无需同时安装。刷新后，控制台临时注入会消失，安装的用户脚本会重新启用。

构建方式为 npm run build；只构建独立助手可运行 node scripts/build-programming-paste.js。测试为 node --test tests/programming.test.cjs。

## 1.0.8：无注释默认规则与运行纠错

- 初次生成及运行后的修正请求均要求：除非题目明确要求，否则源代码不写注释。粘贴/解析不会直接删除 # 等字符，防止破坏字符串、预处理指令或题目要求的注释。
- 每次回填后点击本题的原生“运行”，只读取本次新产生的结果；全部 result_right 才认定通过。编译错误、运行异常、测试用例不通过均进入纠错。
- 纠错请求带原题（含当前编程语言及图片）、当前完整代码和完整运行错误，通过原有 AI API 或 DeepSeek 网页来源发送，绕过旧答案缓存。
- 每题最多运行 3 次：初次 1 次，失败后最多 2 次修正并运行。第 3 次仍失败则记录原因、保持未完成状态并继续下一题，不再发送第 3 次纠错请求。
- 已有代码先运行验证；只缓存通过运行的完整代码。错误代码不写入缓存，失败后移除本题缓存。未知或过期运行结果、服务不可用和运行超时不当作通过。
- 暂停期间不点击运行、不发送纠错及回填；停止或手动修改代码会阻止旧结果继续写回。答案检验中接受的程序也必须通过一次运行，才能提交为已接受答案。

浏览器验证采用当前页面的原生运行按钮和结果回调，对运行接口返回作本地模拟，并使用模拟 AI 修正：验证了失败后第 2 次通过、连续失败第 3 次跳过，以及原题/代码/报错完整传递。未调用真实 AI 或提交作业，验证后恢复原有内容。

1.0.8 验证结果：完整回归 116 项通过，含程序题 29 项；TypeScript 编译、完整构建及安装脚本语法检查通过。浏览器证据位于 output/playwright/programming-runner-live-verification.json。

# 课程学习更新与验证：1.0.15

验证日期：2026-11-06。

本次更新聚焦视频暂停后续播、故障恢复、学习控制与完成状态确认。交付文件为 `dist/xuexitong-ai-helper.user.js`，需在脚本管理器中导入并覆盖旧版；浏览器测试使用受限配置注入，不代表已安装到用户的日常脚本管理器。

## 实现与回归

| 改动 | 行为与证据 |
| --- | --- |
| 暂停后续播 | 合并播放请求；原生 `play()` 被中断时继续轮询，不把 `AbortError` 当成任务结束。覆盖连续暂停、取消与跨 frame 异常。 |
| 有限恢复 | 网络失败、持续卡顿或播放器元素替换最多恢复 2 次；保留上次观察到的进度。断网时等待联网，后台长时间挂起不直接算卡死。真正的解码/格式错误或重试耗尽时保留原因和重试入口。 |
| 学习控制 | 新增暂停、继续、停止、重试当前页面及最多 30 条运行记录。暂停冻结调度等待和跳转倒计时；停止取消播放恢复与后续跳转。直接挂载跨 frame 控制面板，避免消息组件序列化导致按钮失效。 |
| 平台完成确认 | 必需任务执行后等待 `isPassed === true` 或 `ans-job-finished` 等明确标记；30 秒仍未确认时停止跳转。缺少标记不当成完成。 |
| 目录兼容 | 接受新版 `icon_Completed`；缺失或非法任务数量作为未知状态处理，避免误报全部完成。 |
| 进入课程行为 | 增加独立的“进入课程时定位未完成任务”开关，与复习模式分开配置。 |

主要源码：`packages/scripts/src/utils/study.ts`、`study-media.ts`、`study-controls.ts`，以及 `packages/scripts/src/projects/cx.ts`。

## 登录后真实浏览器验证

使用 Chrome / Playwright，在用户已登录的学习通课程中选择一个已经完成的视频，以 1 倍速、静音测试。实际执行章节调度和媒体运行器；测试配置关闭章节答题、视频答题和自动跳章，并阻断作业、考试、视频题目请求以及外部 AI 请求。没有操作或提交用户作业、考试、章节测试或视频题目。

以下 7 项通过：脚本按禁用答题配置启动；原生暂停后自动继续；面板暂停保持进度；继续按钮恢复播放；真实断网重连后恢复进度；停止后不再自动播放；重试只创建一个学习任务且可再次停止。

断网前进度为 **6.575 秒**，恢复后的首次观测为 **6.205 秒**，随后继续播放。实际发现断网时播放器可能同时给出原生错误码 4 和“格式不支持或者服务器或网络的问题”提示，因此恢复决策结合在线状态及原生媒体错误，不再仅凭模糊提示文本终止。

本地证据：`output/playwright/production-study-results.json`、`production-study-controls.png`、`production-study-check.cjs`。最终浏览器已联网，视频和学习任务均停止；测试页未报告脚本异常。

## 验证边界

- 本次没有让一个未完成任务在真实后台从未完成变成完成。平台确认逻辑由本地延迟/超时回归和真实已完成标记检查支持，不代表已验证新增学习记录或所有课程。
- 曾观察到真实媒体解码错误（错误码 3）；这类故障保留停止和手动重试处理，不承诺自动修复损坏资源。
- 跨域计时阅读页的完整暂停联动，以及其他课程的特殊播放器尚未做真实验证。
- 字体识别升级与更广的站点域名支持未纳入本轮实现。

审查结论：本轮视频控制与恢复路径通过；上述未覆盖范围保留验证边界。

# Changelog

所有重要变更会记录在此文件中。

## 1.0.6 — 2026-10-17

- DeepSeek 网页模式打开题目页时即使专用页未连接，也会按原倒计时进入可取消的等待；连接后自动开始。取消倒计时、暂停、停止及切换来源会阻止延迟启动。
- 临时断连保留原请求邮箱和随机编号，最长等待恢复 30 分钟；恢复后继续读取原回答，不重新填写题目或上传附件。明确停止或连接被其他标签页接管时不自行恢复。
- 已启用专用页刷新或前进/后退恢复时，使用当前标签页内的授权和请求编号重新关联原消息；恢复后的限流重试仍只点该消息的原生按钮，并保持至少 3 秒间隔。
- 保存当前专用会话的用量和上一回答编号，刷新后可继续下一题，第 50 次完成后仍正常切换会话。不能确认原消息时明确停止，避免重复发送。
- 任务占用在短暂断连时保持续租；新增持续状态、等待时长及长时间无进展提示。请求异常会暂停后续题目，避免整队题目因同一个断线错误快速失败；章节测验也提供暂停/继续和停止。
- 修复暂停与断线重叠时等待预算重复累计、恢复后误报超时的问题；停止等待后不会在连接恢复时重新启动。
- 新增晚连接启动、恢复/取消、旧接收端保护、原消息重新关联和八小时虚拟时间回归。完整测试 87 项；长时间样例是本地虚拟时间测试，不代表真实整夜账号验证。

## 1.0.5 — 2026-10-17

- 普通选择、判断、填空与阅读分组题统一核验网页实际作答值；禁用、无效点击、被回滚或控件失效的答案不再计入完成率。
- 连线题校验左列与控件数量、右列标签描述；控件尚未加载完整时停止处理。乱序的 `2-a, 1-b` 按左侧编号转换为 `b#a`，重复或缺失编号不猜测。
- 图片提取覆盖样式表、内联简写和多背景图，加入图片标记时保留元素原有文字。
- 跨框架通信按请求和标签页隔离清理，只接受明确成功状态，补全错误返回、超时清理及并发队列处理。
- 答案检验按实际请求预算和所属框架心跳等待，修复 11 分钟后丢失慢请求结果的问题；支持取消并停止底层请求/重试。
- 暂停作用于每次答案写入、翻页和章节保存/提交；DeepSeek 当前消息的限流重试也随任务暂停。增加“停止”按钮，取消后不再回写或重建请求。
- DeepSeek 专用页从浏览器前进/后退缓存恢复时重建心跳和存储监听，可重新启用；保留当前消息至少 3 秒间隔的限流重试。
- 设置备份保留 `false`、`0`、空字符串；只导出声明的用户设置，版本化校验导入，兼容旧备份并过滤运行数据。设置页增加“设置备份与恢复”入口。
- 清理媒体查找超时和取消后的轮询，视频结束、加载失败或页面离开后释放播放与视频内题目定时器。
- 小屏幕设置改为纵向字段布局，按钮可换行，修复 360px 屏幕输入框和下拉框溢出。

## 1.0.4 — 2026-10-17

- 连线题同时支持旧版 `.line_answer_ct .selectBox` 和新版 `.thirdUlList select` / `select.dept_select`，作业、考试及章节测验共用识别、取值、填写和已答保护逻辑。
- 将左右两列、每个匹配项的题干与图片标记加入 AI 请求，保留真实 `value/data`；未读完整或答案不匹配时不误填、不标记完成。
- 新版原生下拉框填写后派发 `input` / `change` / `chosen:updated`，同步 Chosen 显示，并校验实际保存值。
- 适配新版 DeepSeek 的 429 待发送消息：在带当前请求 ID 的消息行中查找“请求频率过高”和原生重试按钮，至少间隔 3 秒重试，不重新填入题目/上传附件。原等待超时最多延长 10 分钟，可随时停止；登录、验证码及普通错误不自动重试。
- 桥接心跳与任务占用有效期从 45 秒调整为 3 分钟，新增 GM 存储事件唤醒与页面恢复时刷新，减少后台定时器节流导致的误断连。
- 修复上传/发送期间取消后重建已删除请求邮箱的竞态。
- 新增 `pnpm test`：35 项自动回归通过；登录网页上以本地拦截连续模拟 3 次 429 后成功读取正常答案，没有重复题目消息或触发真实服务限流。

## Unreleased

- 移除“AI最大输出”设置与旧配置读写，首次请求、空回答/格式重试、视觉检测均不设置插件固定 token 上限；Anthropic 必填参数自动使用接口提供的模型最大值，缓存不再依赖旧上限。

- 开始/补全按网页实际作答状态跳过已答题，全部完成时提示；重新答题仍可显式重做。
- 已完成题目新增 AI 检验，采用新答案后同步网页、结果与缓存；检验绕过旧缓存，支持跨框架并防止过期建议写入。
- 修复公式答案的 JSON 反斜杠漏转义及控制字符误解析，兼容代码块、尾逗号、多行和渲染后的 LaTeX，保留网页请求编号校验。
- 填空保留公式中的竖线、分号和换行，按答案数组保留分空信息并同步缓存；修复相邻编辑器干扰及选择题公式标点/大小写匹配。

- DeepSeek 网页改为同会话使用 50 次再换，显示用量并验证上一轮请求 ID，防止读取旧回答/借用旧工具栏。
- 网页模式增加由接收端授予的跨标签页任务互斥：手动搜题与整次自动答题不能同时运行，自动答题固定一线程。
- 题目识别后、首个 AI 请求发出前即发布完整待答列表；修复控制面板首次渲染监听晚注册及逐题模式延迟显示。
- 关闭题目页清理标签信号时，不再把空值当作菜单导航，避免 replace 空值报错。
- 移除自定义“AI输出限制”，API/网页统一内置提示词，忽略旧配置，修复默认提示词重复拼接。

- DeepSeek 网页桥接接通题干/选项图片：原生上传、全附件就绪后发送、附件限额与旧版接收端保护；2026-09-20 真实登录页面适配器测试通过。
- 适配新版 DeepSeek role=button 发送与回答工具栏，上传失败/缺图不提交，仍保持每题只发送一次。
- 深色模式的危险按钮改为低饱和底色/边框，长错误说明使用正常文字色，补全悬停和禁用样式。

- 修复 vendor GM 存储在新标签页启动时删除其他标签页信号，导致导航跳回首页、正在搜索的结果丢失的问题。
- 模型答案展示不再执行 HTML；填空内容也按文本写入。

- 深色主题覆盖旧版高优先级样式、焦点/禁用按钮、下拉框、弹窗和结果区；CSS 成为唯一样式来源。
- 重写答题调度：启动单飞、统一请求间隔、等待真实请求完成、关闭后不写答案；逐题模式处理最后一题并验证翻页变化。
- 关闭或清空持久缓存时仍合并相同的在途请求；空回答与格式修复共用一次重试额度。
- 填空触发 input/change，富文本答案按纯文本写入；分组选择必须全部有效才标记完成。
- 图片检查包含选项相邻图片；API 模式未确认视觉能力时先跳过；网页模式通过原生附件通道传图。
- 新增需显式启用的 DeepSeek 网页实验桥接：单接收端、独立请求编号、串行处理、超时/中断不重发。不读取登录凭据。
- 贡献/安全文档移至 .github，更新日志移至 docs；清理重复样式和本地生成文件。

- 学习功能作用域仅保留学习通；DeepSeek 白名单仅运行可选接收端，移除泛教育域名和其他学习平台。
- 导航点击直接渲染，不再依赖存储变更回调；快速切换时丢弃过期渲染。
- 图片提取覆盖题干、选项、图片根节点和懒加载地址；保留图片选项的位置。
- 选择题使用实际选项范围，支持 E–Z、多选字母规范化和有上限的格式纠错，不强迫多选至少选两项。
- 重建答案缓存：完整题目/AI 配置指纹、7 天有效期、200 条上限、并发去重、关闭时不读写及手动清空。
- 增加随系统切换的深色主题、小屏幕布局和精简首页；模型可手动输入并使用列表建议。
- 视觉能力改为三态识别：接口元数据、实际请求反馈、可选付费随机图片核验及手动覆盖。
- 修复请求超时/HTTP 错误处理、配置事件监听清理及数值设置的零边界。
- 增加离线回归测试和浏览器冒烟测试。
